# Keyboard shortcuts

With a hardware keyboard, hold **⌘** to see every shortcut in iPadOS.

## File and edit

| Shortcut | Action |
|---|---|
| ⌘N | New project |
| ⌘O | Open from Files |
| ⇧⌘O | All projects |
| ⌘S / ⇧⌘S | Save / Save as |
| ⌘E | Export |
| ⇧⌘E | Export again |
| ⌘G | Export GIF |
| ⌘, | Preferences |
| ⌘Z / ⇧⌘Z | Undo / Redo |
| ⌘C ⌘X ⌘V | Copy, cut, paste |
| ⌘A | Select all |

## Drawing

| Shortcut | Action |
|---|---|
| B | Brush |
| E | Eraser |
| G | Fill |
| I | Eyedropper |
| L | Lasso |
| [ / ] | Smaller / bigger |
| Return / Esc | Apply / cancel selection |
| ⇧H | Flip selection |
| ⇧⌘⌫ | Clear layer |

## View

| Shortcut | Action |
|---|---|
| ⌘= / ⌘− | Zoom in / out |
| ⌘0 | Fit canvas |
| H | Flip view |
| ⌃⌘F | Zen mode |
| O | Onion skin on / off |

## Frames and layers

| Shortcut | Action |
|---|---|
| Space | Play / pause |
| ← / → | Previous / next frame |
| ⌥N | New drawing (new frame with Sync layers) |
| ⌘D | Duplicate drawing |
| ⌫ | Delete drawing |
| ⌥← / ⌥→ | Move frame earlier / later |
| ⌥= / ⌥− | Hold longer / shorter |
| ↑ / ↓ | Layer above / below |
| ⇧⌘N | New layer |
