# Atajos de teclado

Con un teclado físico, mantén pulsado **⌘** para ver todos los atajos en iPadOS.

## Archivo y edición

| Atajo | Acción |
|---|---|
| ⌘N | Nuevo proyecto |
| ⌘O | Abrir desde Archivos |
| ⇧⌘O | Todos los proyectos |
| ⌘S / ⇧⌘S | Guardar / Guardar como |
| ⌘E | Exportar |
| ⇧⌘E | Exportar de nuevo |
| ⌘G | Exportar GIF |
| ⌘, | Preferencias |
| ⌘Z / ⇧⌘Z | Deshacer / Rehacer |
| ⌘C ⌘X ⌘V | Copiar, cortar, pegar |
| ⌘A | Seleccionar todo |

## Dibujo

| Atajo | Acción |
|---|---|
| B | Pincel |
| E | Goma |
| G | Relleno |
| I | Cuentagotas |
| L | Lazo |
| V | Mover |
| [ / ] | Más pequeño / más grande |
| Retorno / Esc | Aplicar / cancelar selección |
| ⇧H | Voltear selección |
| ⇧⌘⌫ | Vaciar capa |

## Vista

| Atajo | Acción |
|---|---|
| ⌘= / ⌘− | Ampliar / reducir |
| ⌘0 | Ajustar lienzo |
| H | Voltear vista |
| ⌃⌘F | Modo Zen |
| O | Papel cebolla sí / no |

## Fotogramas y capas

| Atajo | Acción |
|---|---|
| Espacio | Reproducir / pausa |
| ← / → | Fotograma anterior / siguiente |
| ⌥N | Nuevo dibujo (un fotograma entero con Todas) |
| ⌘D | Duplicar dibujo |
| ⌫ | Eliminar dibujo |
| ⌥← / ⌥→ | Mover fotograma antes / después |
| ⌥= / ⌥− | Mantener más / menos |
| ↑ / ↓ | Capa de arriba / de abajo |
| ⇧⌘N | Nueva capa |
